kind: debt
tags: bug
created: 2026-07-25T18:17Z

- 2026-07-25T18:18Z "Mos" is Moses's canonical abbreviation (pearl_of_great_price:
"Moses:Mos/mose"), while Mosiah (book_of_mormon: "Mosiah/mosi") has no
abbreviation. So find_book("Mos") short-circuits to Moses via the
exact-name/abbrev match, and "Mos 3" meaning Mosiah 3 silently resolves to
Moses 3. Verified: find_book("Mos") -> Moses, find_book("Mosi") -> Mosiah.

The unique prefixes are already correct ("mose" vs "mosi", 4 chars needed to
disambiguate), but the abbrev/exact-name path wins before the unique-prefix
logic runs. Decide the intended behavior for the genuinely ambiguous "Mos"/
"mos" prefix (prefer one? refuse as ambiguous? context by collection?) and
make find_book honor it. Add tests for Mos/mos/Mosi/Mose. Lives in books.py
find_book() and the two book definitions."
